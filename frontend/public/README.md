# frontend/public

Static files served from the site root.

- `doctor.jpg` — optional. If present, the video visit shows this photo as the
  remote doctor whenever no doctor stream is connected (or when the
  **Simulate Doctor** demo toggle is on). With no file here, a built-in SVG
  portrait is used instead, so the demo works offline with zero assets.
  Recommended: a landscape headshot, ~800×600 or larger.
